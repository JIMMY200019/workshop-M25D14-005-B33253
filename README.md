## Project Description
This project is a simple workshop registration form for Campus Create. It allows a user to enter their personal details, choose a workshop, select a preferred date, pick the number of seats, confirm a practice password, and preview their registration before submission.

The project demonstrates front-end form validation, dynamic workshop selection, password confirmation checks, and styling for a responsive registration page.

## Instructions for Running the Project
1. Open the project folder in a browser.
2. Launch the file named `index.html` directly in your browser.
3. If you are using a local server, you can run:

   ```bash
   python -m http.server 8000
   ```

4. Then open:

   ```text
   http://localhost:8000
   ```

## Files Included
- `index.html` — page structure and form markup
- `styles.css` — styling for the layout and form
- `app.js` — dynamic workshop options and validation logic
